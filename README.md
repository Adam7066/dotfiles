# Smallten's dotfiles

使用 [chezmoi](https://github.com/twpayne/chezmoi) 管理 dotfiles。

使用系統：
- macOS
- Arch Linux

目前包含：
- zsh、zimfw、p10k

## 📦 Installation

1. 安裝 chezmoi
    ```bash
    # macOS
    brew install chezmoi

    # Arch Linux
    pacman -S chezmoi
    ```
2. 直接套用：`chezmoi init --apply https://github.com/Adam7066/dotfiles.git`
