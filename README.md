# Smallten's dotfiles

## 簡介
使用 [chezmoi](https://github.com/twpayne/chezmoi) 管理。

系統環境：
- macOS
- Arch Linux

## 📦 Installation

1. 安裝 chezmoi：
    ```bash
    # macOS
    brew install chezmoi

    # Arch Linux
    pacman -S chezmoi
    ```
2. 直接套用：
    ```bash
    chezmoi init --apply git@github.com:Adam7066/dotfiles.git
    ```
